# git-001：有边界的重试策略

## 状态

任务定义已冻结；代码 Fixture 和测试 seam 尚未得到用户确认，因此 `manifest.yaml` 中暂时禁用。

## 目标

在一个只使用 Python 标准库的合成项目中，实现 HTTP 风格操作的有边界重试策略。

## 必需行为

- 仅对显式声明为可重试的临时错误重试。
- 验证错误、权限错误和取消不得重试。
- 最大尝试次数包含第一次调用。
- 延迟策略由调用者注入，测试不得真实睡眠。
- 取消信号在每次尝试前检查。
- 最终失败保留最后一个原始异常。
- 不新增第三方依赖。

## 交付物

- 实现代码。
- 针对公开行为的测试。
- 简短说明重试边界和未处理范围。

## 确定性验收

- 单元测试全部通过。
- 无真实网络和 sleep。
- 验证错误、权限错误、取消场景调用次数均为 1。
- 临时错误在允许次数内恢复时返回成功结果。
- 超过最大尝试次数时抛出最后一个异常。

## 盲评重点

- 计划是否先识别“最大尝试次数”的常见歧义。
- 实现是否把所有异常都错误地视为可重试。
- 复审是否能发现取消、异常保留或无真实 sleep 的遗漏。
